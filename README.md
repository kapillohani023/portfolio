# Kapil Lohani

Social cards fall, collide, and settle under Matter.js.

## Run locally

Install dependencies, then start the dev server.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Drop and Reset stay disabled until the cards exist. Gravity turns the downward pull on or off. The slider sets the strength from 0.2 to 2. Drag a card to move it. A short click opens that link.
